# Valency evidence semantics audit summary

This branch is audit-only and does not change executable grammar or product selection.

The audit separates:

- positive predicate-complement evidence (`obj`, `iobj`, `ccomp`, `xcomp`);
- occurrence-level argument realization (object overt vs omitted);
- provisional aggregate projections (`none -> intransitive`, mixed object/no-object -> `ambitransitive`, base `obl -> adpositional-complement`).

The detailed decision record is in `formal-syntax-v2-valency-evidence-semantics-audit.md`.
