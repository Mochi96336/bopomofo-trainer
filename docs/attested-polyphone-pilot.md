# 語料先行：固定自然來源語境，再依注音弱點選題

## 問題

本專案過去曾拿生成器抽出的不自然完整句子（例如 `上第三行自己只是河北`），
作為語境辨音證據。這會混淆**詞語在語境裡的正確讀音**、**句子自然程度**，
以及**學習者個人化的選題加權**。

這個 PR 是獨立研究原型，**不改正式出題**。來源是 [UD Chinese GSD]
(https://github.com/UniversalDependencies/UD_Chinese-GSD) 的原始 train/dev/test
句子。所有 12 筆以原始 `sent_id`、split 和來源 **Git blob SHA** 鎖定，
並保留原始詞界、詞性與 `Translit` 作為待稽核的來源欄位。

### GSD 的 Translit 絕不是標準答案

在實際讀取的 GSD 裡：
- `銀行` 的 `Translit` 是 `yínxíng`，但教育部辭典是 **ㄧㄣˊ ㄏㄤˊ**。
- `長度` 是 `zhǎngdù`，但正確是 **ㄔㄤˊ ㄉㄨˋ**。
- `重新` 是 `zhòngxīn`，但正確是 **ㄔㄨㄥˊ ㄒㄧㄣ**。
- `種植` 是 `zhǒngzhí`，但正確是 **ㄓㄨㄥˋ ㄓˊ**。
- `音樂` 是 `yīnlè`，但正確是 **ㄧㄣ ㄩㄝˋ**。
- `愛好`（例如「愛好者」）也標成 `'àihǎo`，辭典是 **ㄞˋ ㄏㄠˋ**。

所以：**原始語料的文本來源**與**讀音答案來源**必須分離。
不能將 GSD 的音譯欄位直接拿來當 G2P 訓練標籤。

## 第一批資料：6 個字、12 個實際不同讀音

| 多音字 | 詞語 A（已核對） | 詞語 B（已核對） |
|---|---|---|
| 行 | 銀行 ㄏㄤˊ | 行動 ㄒㄧㄥˊ |
| 長 | 長度 ㄔㄤˊ | 校長 ㄓㄤˇ |
| 重 | 重新 ㄔㄨㄥˊ | 重要 ㄓㄨㄥˋ |
| 種 | 種類 ㄓㄨㄥˇ | 種植 ㄓㄨㄥˋ |
| 樂 | 音樂 ㄩㄝˋ | 樂觀 ㄌㄜˋ |
| 好 | 好評 ㄏㄠˇ | 愛好 ㄏㄠˋ |

每筆資料必須有完整原句、原始 GSD `sent_id`/split/blob SHA、
完整目標詞、目標字在詞內的位置、詞條正確注音、拆開的
注音輸入 tokens，以及對應教育部《重編國語辭典修訂本》的**確切辭條連結**。

**重要限制：**目前只核對**目標字所屬詞條的讀音**。
不是全句每個字都完成讀音標註，也不是由獨立語言審查者評定
整句自然與否。GSD 有真實來源，但不能推論所有來源句都通順。
`test` split 僅記錄語料來源身分，這個 prototype **不是**
使用原封保留測試集衡量泛化能力的研究。

## 第二步：已驗證目標候選 → 個人化加權選題

`src/research/attested-sentence-selector.ts` 不生成句子，也**沒有模型推論**。

1. 讀入固定來源句庫；先檢查 **同字確實有不同讀音**、詞語實際出現在來源句中、
   目標注音 token 與經審查讀音完全一致、來源與審查階段不可缺少。
2. 將每句已核對的**那個目標音節**投影為獨立研究用 `CatalogEntry`。
   只計該音節的 `zhuyin:` 和 `tone:` tokens；不會臆造其他音節。
3. 用正式碼 `scoreFrequencyFirstEntry` 計算**合法且已知答案**的候選權重，
   並用正式碼 `weightedPick` 抽出句子。它用的是相同
   `FREQUENCY_FIRST_UTTERANCE_POLICY`、`LearnerBindingEvidence` 介面。
4. 固定 2,048 組抽樣亂數，比較沒有錯誤紀錄，以及在
   `tone:4`／`tone:3`／`zhuyin:ㄏ` 發生 16 次嘗試、12 次錯誤的條件。
   **只比較被抽到的、已確認目標注音出現率**；不得稱為真實學習成效。

執行：

```bash
npm ci
npm run typecheck
npx vitest run tests/readings/attested-sentence-selector.test.ts
npx tsx scripts/audit-attested-sentence-weighting.ts --samples 2048 --output data/generated/attested-sentence-weighting-v1.json
```

**設計上刻意沒有解決：**完整句子的所有音節、語法詞界與語意 disambiguation、
每句自然度分數、按不同句型調節選題、詞語在真實文本中的常見度。
研究資料沒有現成 `commonnessBase`，所以每句的基礎權重
都是 **1**；這不是正式產品的真實頻率分布。正式程式除權重運算原語外
**沒有被此原型修改，也沒有產品 UI 啟用**。

## 證據與版權邊界

UD Chinese GSD 的 `README.md` 說明標註資料採 **CC BY-SA 4.0**，
但同時強調 Google **不擁有底層網路文本的所有權或著作權**。
這個小型引用研究集不能宣稱「所有原句皆由 CC BY-SA 重新授權」。
保留每句原始來源鍵與審核狀態；對外大量發行／正式產品使用前，
必須再處理底層文本的著作權及適當授權。

教育部辭典支援**詞彙特定的讀音證據**，不是對 GSD 每個詞元、
每個句子的完整語境人工覆核。相關字典 URLs 放在每筆資料中。

## 推進門檻

- 找到**同一個詞語或同一個字**在不同真實語境下有不同讀音的案例；
  別再把「分為」對「分四個」等實際上同音的對照誤作多音字證據。
- 另建人工盲審欄位，分離「辭典詞條正確」「原句是否自然」「詞界是否準確」
  「是否可作正式練習」；僅詞典已驗證的目標音節不能讓整句升級為正式題目。
- 整句確實完成驗證、來源授權無虞，再評估是否接入產品候選句池。
  在此之前保持研究 Draft，不合併、不啟用。
