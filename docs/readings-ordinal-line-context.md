# Local lexical-slot repair: the written context 第N行

## Concrete source of the problem

The original deterministic 2,048-seed composer audit, seed 931,
contained `第三` followed by standalone `行`, selected as
`word:行:ㄒㄧㄥ2`. In the clearly numbered-line sense **第三行**,
the correct 行 reading is `ㄏㄤ2`. This is a **local, meaningful
collocation**, not a claim that the entire autogenerated surrounding
sentence is natural.

## What this PR changes

This PR depends on Draft #424, which already makes role-based reading
constraints independent from learner mistakes.

The composer now passes the **previously selected surface-order lexical
entry** into the existing reading-eligibility callback. A punctuation
or grammar literal resets this context.

Only immediately adjacent **atomic ordinal** `第[中文或阿拉伯數字]`
followed by the **standalone `行` lexical entry** must select the
exact `行:ㄏㄤ2` catalog identity. Existing closed-class, pronominal,
and 好/ADJ constraints still apply.

If the initially sampled current-slot lexical identity has an unlicensed
pronunciation, the composer **redraws only that lexical slot from its
licensed candidates**, using the *original actual frequency and learner
weights of each legitimate entry*. It does **not** transfer an invalid
reading's learner weight to the row reading, rewrite the displayed
Bopomofo, throw away the whole sentence, or restart the structural
derivation.

Bare `三行` remains untouched; it does not necessarily convey the
ordinal numbered-line collocation. Whole lexemes such as `行動`,
nonadjacent words, and other uses of `行` remain outside the
reviewed context. A direct mismatch of catalog entry and syntax profile
raises an error rather than hiding an identity problem.

## Evidence and gates

- Deterministic narrow unit tests: exact ordinal context, bare cardinal,
  other words, full lexemes, invalid lexical/profile joins, and
  **maximumAttempts=1** verifying one-slot redraw works without a
  whole-utterance retry.
- Exact 2,048-seed baseline reviewed-role vs ordinal-trial audit.
  Require no wrong 第N行 reading, **0 unrelated seed drift**, and 0
  generation failures, with concrete changed candidates inspected.
- Product uses the same combined callback as the ordinal trial.

This proves a scoped selection invariant only: no human-verified
sentence naturalness, whole-language semantic G2P, or real-user learning
outcomes. Keep Draft until exact-head checks pass; do not merge
automatically.
