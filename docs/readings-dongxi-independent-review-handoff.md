# 東西 GSD train：獨立審查交接與回收程序

**用途**：操作指引；不含已核准的讀音標註，也不改出題器。對象為研究召集人，不應連同本頁或其他研究假說一起交給審查者。

## 發送前

1. 先確認候選審查者未看過本 repo 的第一輪預測或其他人的答案；若曾看過，仍可作公開複核，但不能算作「未受提示的獨立審查」。
2. 只把 [無答案人工作答表](reviewer-packets/dongxi-gsd-train-independent-review-form.md) 的**獨立副本**交給審查者；不要連同 PR、來源 intake、先前研究備忘或 git 網址寄出。
3. 兩位審查者使用獨立檔案，審查前互不討論。記錄發送時的檔案版本和發送日期。
4. 審查者可查閱相同的指定教育部辭典，但需自行查詞並註明使用的詞條；不能直接拿研究者的既有讀音猜測當答案。

## 回收

- 審查者 A/B 分別提交原始填答檔，保留原檔；禁止將兩份整理成單一可覆寫表格後才保存。
- 紀錄代碼、時間、接觸既有答案的自述、逐句四欄判斷與理由；不用收集公開姓名。
- 未兩份均交件前，不把任何一人的結果傳給另一人；兩份都封存之後才揭露 R01–R06 對應來源 ID 進行比對。
- 不在 GitHub 公開原始審查檔中包含姓名或其他個資。原句受上游語料文本授權約束。

## 對照與裁決

逐一比較 6 句 × 4 欄（詞界、自然度、意思、讀音），**不同欄位分開記錄**。保留以下狀態：
- `agree`：兩人同意的原始判斷，並非自動核准金標。
- `disagree`：保留兩份原判斷和理由，交由第三位未參與標註的裁決者。
- `uncertain`：至少一方無法判斷、語境歧義，或詞界需要保留。
- `exposed`：任一方事先看過研究假說；不得宣稱雙盲或獨立一致性。

第三方仍不能確認者維持 `unresolved`。對自然度不合格或詞界不成立的句子，讀音即使一致也不可直接當作可用訓練金標。不得以模型輸出、UD 詞性／Translit 或研究者先前假說投票裁決。

## 完成條件

- 至少兩份實際人工審查原始紀錄已封存，且所有先前答案接觸情況有聲明。
- 每一欄的兩人原始判斷、分歧、後續裁決與未決項目可稽核。
- 使用者先核可授權與資料用途，才另行評估是否建立 **train-only** 金標資料。
- 本批六句不是盲測集；沒有新的隔離測試資料前，不報讀音模型的泛化準確率。
